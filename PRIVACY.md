# Privacy Policy for SPECTRA

**Last Updated: December 27, 2025**

## Overview

SPECTRA is a browser extension that enhances audio and video playback. This privacy policy explains how we handle user data.

## Data Collection

**SPECTRA does not collect, store, or transmit any personal data.**

Specifically, we do NOT collect:

- Personal information (name, email, etc.)
- Browsing history or web activity
- Audio/video content from websites
- Location data
- Any other user data

## Local Storage Only

All user preferences (volume levels, equalizer settings, etc.) are stored locally on your device using Chrome's built-in storage API. This data never leaves your browser.

## Remote Control Feature

The optional remote control feature uses peer-to-peer WebRTC connections. Connection IDs are randomly generated for each session and are not stored on any server. No data passes through any third-party servers.

## Third-Party Services

SPECTRA does not use any analytics, advertising, or tracking services.

## Changes to This Policy

We may update this privacy policy from time to time. Any changes will be reflected in the "Last Updated" date above.

## Contact

If you have questions about this privacy policy, please open an issue on our support page.
